# Mission 01 — Know my computer

## 1. Task / objective

Explain how a computer uses input, processing, output and storage (IPOS), identify hardware and software, and give examples of computer systems used in everyday life.

## 2. Work completed

### Task 1.1 — IPOS example: typing and saving class notes

| Stage | What happens? | Hardware / component |
|---|---|---|
| Input | I press keys to type text into a document. | Keyboard |
| Processing | The application receives the key presses and the processor runs the instructions. Memory holds the document while I work. | CPU and RAM |
| Output | The text appears on the display so I can read it and check for mistakes. | Screen / display |
| Storage | When I save the document, the file is written to storage so I can open it later. | SSD; cloud storage can also keep a copy if enabled |

The stages are connected. The keyboard sends input, the CPU and memory help the application process it, the display shows the result, and saving writes the file to storage.

## 4. My understanding

IPOS is a simple way to describe the main jobs of a computer. Input is the data we give it, processing is the work done on that data, output is the result shown to us, and storage keeps information for later. Hardware is the physical part that can be touched. Software is the set of programs and instructions that tell the hardware what to do.

A laptop is not the only computer system. ATMs, traffic controllers and billing terminals also accept data, process it and produce a result for people.
