## Run the number converter

Python 3 is required. From the repository folder, run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter a non-negative whole number when prompted. The program prints its binary and hexadecimal forms.

## Learning summary

The main thing I understood is that a computer does several connected jobs: it accepts input, processes it, gives an output and stores data. The operating system manages the resources used by programs. The Terminal gives another way to work with files and tools, while Git records changes to a project. I also practised how computers represent numbers and text and how a browser uses a network to load a website.
